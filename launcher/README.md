# OpenMarket Launcher

A Tauri v2 + React/TypeScript desktop app that supervises the OpenMarket
`server/` process instead of running it by hand in a terminal.

See the [main README's "Desktop launcher" section](../README.md#desktop-launcher)
for what it does, how to build it, and known limitations. This file
exists only so the folder isn't left with the generic Tauri template
README.
